# Computer Graphics and Multimedia (CGM) Lab

This repository contains practical programs, lab assignments, and implementations of fundamental concepts in **Computer Graphics and Multimedia (CGM)** using C/C++.

## 📚 Topics Covered

- Basic graphics functions and primitives
- Line drawing algorithms: DDA and Bresenham's Line Algorithm
- Circle drawing algorithms: Midpoint and Bresenham's Circle Algorithm
- 2D transformations: Translation, Rotation, Scaling, Reflection, and Shearing
- 3D transformations
- Clipping algorithms
- Polygon filling algorithms
- Bézier curves and spline curves
- Fractals in computer graphics
- Multimedia concepts and applications

## 🛠️ Technologies Used

- **Language:** C / C++
- **Graphics Library:** `graphics.h` (BGI / WinBGIm)
- **IDE:** Visual Studio Code
- **Compiler:** GCC / MinGW

## ⚙️ Setup and Execution

1. Clone this repository:

   ```bash
   git clone <repository-url>
   ```

2. Open the project folder in Visual Studio Code.

3. Ensure that a compatible C/C++ compiler is installed.

4. For programs using `graphics.h`, configure the required BGI/WinBGIm headers and libraries.

5. Compile and run the program using the appropriate compiler commands for your setup.

## 🎯 Objectives

- Understand the fundamental principles of computer graphics.
- Implement graphical algorithms using programming.
- Explore 2D and 3D transformations.
- Learn curve generation, clipping, and polygon filling techniques.
- Develop practical problem-solving skills through laboratory experiments.
